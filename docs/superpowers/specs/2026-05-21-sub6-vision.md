# Sub #6 — Multimodal Vision

**Date:** 2026-05-21
**Depends on:** Sub #2 (browser screenshots)

## Goal

Pass images (browser screenshots, ticket attachments) to the LLM as multimodal content blocks. Anthropic Claude + GPT-4V style.

## Module

`aiforge_core/runtime/vision.py`

## API

```python
def attach_image(text: str, image_path: str | Path) -> list[dict]
def supports_vision(model_id: str) -> bool
```

`attach_image` returns LiteLLM-shaped content blocks:

```python
[
  {"type": "text", "text": "<original prompt>"},
  {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}},
]
```

`supports_vision` consults a static allowlist of model IDs known to handle multimodal inputs (claude-opus / claude-sonnet / gpt-4-vision / gemini-pro-vision / qwen2-vl).

## Implementation

- Read image, base64 encode.
- Cap raw image at 5 MB (LLM input limit).
- Detect mime from header bytes (PNG / JPEG / WebP / GIF).
- Soft-error on missing file / oversized / unknown format.

## Tests

- attach_image happy (PNG)
- attach_image missing file
- attach_image oversized
- supports_vision allowlist hits + misses
- mime detection on PNG/JPEG/WebP headers
